# 自审查清单（第 7 步）

提交给用户之前逐项过一遍。任何一项打不了勾，就回去改，别进入用户审查。

## 完整性

- [ ] 有没有 `TODO`、`TBD`、`待定`、`???`？
- [ ] 有没有"等等""之类的"这种开放式列举？
- [ ] 每个组件的职责都写了吗？每个接口都写了吗？

## 一致性

- [ ] 第 1 节的目标和第 11 节的验收标准对得上吗？
- [ ] 第 5 节选定的方案，和第 6/7/8 节描述的实现一致吗？
- [ ] 术语前后一致吗？（同一个东西别有两个名字）
- [ ] 图和第 5/8 节的文字描述矛盾吗？

## 歧义

- [ ] 有没有出现"应该""可能""大概""一般"？
- [ ] 有没有没定义的术语？每个专有名词第一次出现时定义了吗？
- [ ] 有没有"优化一下""处理一下"这种没有谓语的动词？
- [ ] 一个读者只读这份文档，能不能不再问你就能实现？

## 风险

- [ ] 最贵、最不可逆的决策单独标出来了吗？
- [ ] 每个失败模式都有对应的行为吗？
- [ ] 第 12 节的未决问题都有人认领吗？
